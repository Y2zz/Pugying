# 媒体账号

媒体账号属于当前本机数据目录。列表展示账号头像、显示名称、平台名称、账号 ID、保存的授权状态与最近授权时间；可同时按平台、授权状态、名称 / 平台昵称 / 账号 ID 筛选。

## 名称

- `displayName` 是蒲公英内的显示名称，首次添加默认使用平台昵称，可由用户修改。
- `platformNickname` 独立保存平台昵称，在授权成功后更新。
- 重新授权、重新添加同一个账号或创作者中心关闭后回写凭证，均保留已有显示名称。
- 旧库升级只增加可空的 `platformNickname` 列，不猜测或修改原有名称。旧账号在下一次成功授权时补充平台昵称。

## 授权

- 正常账号可打开创作者中心，也可从更多菜单主动重新授权。
- 异常账号显示「需重新授权」及对应的文字按钮。
- 重新授权前必须取得平台用户 ID；已记录 ID 的账号必须与此次登录身份一致。身份缺失、身份不同或请求中的两份 ID 相互矛盾时，保留原凭证、名称与状态。
- 旧账号没有平台用户 ID 时，首次确认身份会补充 ID，但不能占用另一个已绑定账号的身份。
- 用户可在登录阶段退出授权，迟到的授权结果不会保存。保存阶段不可退出，以免产生「已取消但实际保存」的误导。
- 普通授权成功使用简短提示，并清除筛选、定位和突出对应账号；缺少便于识别的名称时提供命名入口。

## 分页

列表采用前端页码分页，每页固定 12 个账号。底栏显示筛选后的账号总数与当前页 / 总页数，多页时提供上一页、页码和下一页；单页时保留数量信息，隐藏翻页操作。

搜索或切换平台、授权状态后回到第一页。删除最后一页的末个账号时回到有效页；新增或重新授权后清除筛选，跳到对应账号所在页并突出显示。

## 列表与反馈

「刷新」只读取本机保存的账号信息，不检测平台当前登录是否有效。刷新期间保留已加载卡片，失败后可重试；旧列表请求不能覆盖已成功修改或移除的账号。

打开创作者中心失败的提示留在对应卡片，名称修改与移除失败的提示留在各自弹窗。未知错误使用简短重试提示，不展示内部错误码。

「移除账号」只移除蒲公英内的绑定，不注销平台账号；再次使用时需重新添加。
