# 作品管理

作品管理统一展示文章、图文和视频，保留服务端搜索、类型筛选与每页 20 条的分页。

## 状态规则

列表状态由分发账号结果优先决定，不使用内容的历史 `published` 标记作为成功依据。内容级 `draft/published` 数据及发布编排不变，无需数据库迁移。

| 优先级 | 条件                               | 筛选入口 | 列表标签 |
| ------ | ---------------------------------- | -------- | -------- |
| 1      | 任意账号排队或运行中               | 发布中   | 发布中   |
| 2      | 任意账号失败或取消，且无账号运行中 | 需要处理 | 需要处理 |
| 3      | 至少一个账号，且所有账号成功       | 已完成   | 全部完成 |
| 4      | 部分账号成功，其余未发布           | 待发布   | 部分完成 |
| 5      | 无发布结果，内容为草稿             | 草稿     | 草稿     |
| 6      | 其他无发布结果内容                 | 待发布   | 待发布   |

取消数量独立显示，不计入失败数量。成功表示发布流程完成，不代表平台审核通过或已公开；目前不接入审核结果。

## 筛选与数量

`GET /contents` 支持 `managementStatus=draft|pending|publishing|needs_attention|completed`，无状态参数时查询全部。响应新增 `counts`，包含全部及五种状态数量。

类型和关键词同时作用于列表与状态数量；数量忽略当前状态选项和分页。关键词仍匹配标题、正文及标签，并将 `%`、`_` 等视为普通字符。SQLite 通过分发记录计算状态、筛选后再分页，排除软删除作品，使用更新时间及 UUID 保持排序稳定。

## 账号详情与操作

- 详情显示平台图标、平台名称、当前账号名称、状态和开始/完成时间。账号已移除或读取失败时展示对应说明，不展示账号内部 ID。
- 成功记录有有效 HTTP/HTTPS 地址时提供「查看平台作品」，由已有桌面外链机制打开系统浏览器。
- 授权失效引导到媒体账号重新授权；素材缺失引导回编辑页；其他失败可重试，取消可重新发布。每次仅重试选中的账号，不触发已成功账号。
- 草稿显示「继续编辑」；其他作品显示「编辑本机内容」。本机编辑不会同步修改平台作品。发布期间列表不允许编辑或删除。
- 删除仅移除本机作品及关联分发记录，不删除平台作品或原始媒体文件；本轮不提供回收站与恢复入口。

## 更新机制

- 发布进行中或本页发起重试时，每 3 秒刷新；空闲时每 15 秒刷新。窗口隐藏时跳过轮询，回到窗口时刷新。
- 更新保留现有列表，不反复替换成骨架。请求失败保留已加载的数据，显示简短错误提示。
- 打开的分发详情按作品 ID 独立读取，即使重试成功后作品退出当前筛选，详情仍更新。
- 筛选切换、关闭详情与页面卸载会丢弃旧请求结果；结果变少后回到合法页。
- 账号信息初次进入、窗口聚焦及账号同步事件时更新；「刷新」与「刷新详情」也可重新读取。

本轮不包含平台/账号筛选、复制作品、批量操作、回收站和平台审核状态。
