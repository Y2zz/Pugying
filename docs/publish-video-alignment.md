# 视频发布字段对齐

## 核实方式与范围（2026-10-05）

使用当前已登录账号进入[抖音创作者上传页](https://creator.douyin.com/creator-micro/content/upload)，经用户明确授权上传本机临时生成的两秒纯色视频，进入实际视频编辑页。测试输入、权限、定时回显以及由同一测试视频生成的横竖封面上传保存，未点击发布或暂存离开。测试素材不是用户作品。

视频页面目前只提供抖音账号。其他平台尚未接入，不能直接沿用文章、图文或抖音视频的规则。

封面不是强制双封面的依据来自后台的推荐文案。未在本次核实中提交作品，因此并未验证最终发布成功、平台审核或所有格式/编码组合。

## 发布适配器的变化

- 编辑页就绪以实际标题框和 Slate 简介出现为准，不再仅凭 URL 判断。
- 标题、简介和话题完整输入，不静默截断。
- 权限、自主声明和发布时间设置失败时保留创作者窗口并返回未自动完成的结果。
- 不再向同一个图片 input 连续挂载横竖两张封面；按比例槽位分别打开编辑面板并上传，确认图片回显变化。兼容保存后出现的“编辑封面”入口，以及首次保存横封面时的竖封面推荐弹窗。
- 本机 API 与发布入口允许无自定义封面或单张封面的视频分发；文章、图文的封面约束保留。
- 已实测两张自定义封面分别上传、保存并回显不同图片，且编辑弹窗关闭。未提交真实发布，最终发布回执和审核尚未验证；适配器无法确认字段或封面时不会自动点击发布。
