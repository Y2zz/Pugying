# 文章编辑器功能调研

核对日期：2026-10-05。范围为当前文章发布渠道：抖音文章、今日头条文章、哔哩哔哩新版专栏。小红书、视频号在本项目属于图文/视频渠道，不作为富文本文章编辑器的对齐对象。

本次只读取后台界面、工具栏与扩展菜单，没有输入文章、上传图片、保存草稿或发布。工具栏存在某项功能，不代表其输出格式可直接用于其他平台；兼容性需另行验证。

产品范围：根据用户确认，编辑器不支持平台专属内容，包括平台卡片、投票、置顶视频以及站内资源组件；也不支持代码块、公式、表格。这些功能仅作为调研观察记录，不进入开发计划，也不规划其转图片功能。编辑器聚焦文字排版、图片和基础编辑体验。

- [头条文章后台](https://mp.toutiao.com/profile_v4/graphic/publish)：已有登录页面，正文工具栏、更多菜单、导入入口、自动保存和预览。
- [B 站新版专栏后台](https://member.bilibili.com/york/read-editor)：当前页面的工具栏、目录、手机预览、加号菜单。页面可读取，未核实各内容组件的账号权限或提交行为。
- [头条创作者帮助中心：图文创作](https://baike.toutiao.com/detail/211/212/214)：文章创作流程和站内文章链接说明。

不使用旧版专栏教程或普通创作者视频推断当前工具栏。

## 本地现状

核对 `ArticleRichTextEditor.tsx`、`PublishArticle.tsx` 和 `use-article-composer.ts`：

- 已提供加粗、斜体、下划线、单一二级小标题、引用、有序/无序列表、链接和多图插入。
- 图片已有本机多选、拖入/粘贴文件处理、裁剪、替换、删除、图片描述，以及图片前后进入正文的操作。不能重复列为待新增。
- 图片导入要求取得本机文件路径；剪贴板截图等没有路径的图片不应被视为已经完整支持。
- 使用 StarterKit，已有编辑历史及部分节点的底层能力；撤销/重做、删除线、分割线、代码等没有工具栏入口。不能把没有按钮等同于底层完全没有能力。
- 格式按钮没有绑定当前选区状态，也没有 `aria-pressed`；没有清除格式入口。
- 链接使用原生 `window.prompt`，没有显示当前地址的编辑面板和明确的移除入口。
- 目前只有手动保存草稿/修改入口，没有自动保存和正文阅读预览。
- 工具栏随页面滚动；长文缺少保持可见的工具栏、目录和专注写作区域。
- 超过最大字数时 `onUpdate` 直接恢复上次正文；需要明确反馈，避免用户不明白为什么粘贴内容消失。

## 建议顺序

### 第一批：共同编辑体验

1. 格式按钮反映选区状态，加粗/列表等显示按下状态；撤销/重做根据历史可用性禁用。
2. 增加撤销、重做、清除格式入口及快捷键提示。清除文字样式与恢复普通段落的行为要明确，避免清掉图片和内容。
3. 用现有组件体系提供链接编辑面板：显示当前地址、修改、移除；处理未选文字和不允许的地址。
4. 将小标题改为段落样式选择；先核对平台实际层级，内部保留语义，输出时做映射。
5. 增加固定工具栏和专注写作区域，保留现有图标工具，不把所有高级选项堆成一长排。
6. 粘贴时整理 Word/网页带来的无关样式，保留标题、列表、引用、链接与图片等结构；对于无法保留的内容给出简短反馈。
7. 字数超限有明确反馈；正文图片数量、不可读取的素材和账号平台约束在编辑时可见。

### 第二批：长文和安全保存

1. 本地自动保存与恢复，显示保存中/已保存/失败；需要覆盖正文、封面和账号设置，处理异步图片操作及用户切换草稿。
2. 阅读预览，并允许选择平台查看预期效果。未经平台输出验证时标为本地预览，不能承诺与平台完全一致。
3. 根据标题生成可折叠目录，点击定位；长度较短时不占据常驻侧栏。
4. 补齐无本机路径的剪贴板图片导入：先落到本机素材文件再插入，保持媒体存储边界。
5. 支持文档导入；优先 Markdown/HTML，Word 需处理嵌入图片和清理样式，不承诺像素级还原。

### 第三批：能力适配后再加入

| 能力                   | 推荐处理                                                                 |
| ---------------------- | ------------------------------------------------------------------------ |
| 删除线、分割线、对齐   | 先加入平台能力表，验证发布后结果；可放在更多格式里                       |
| 文字颜色、背景色、字号 | 限定少量选项；按平台支持情况输出。业务 UI 字号规范与文章内容样式分别处理 |

共同正文使用语义节点保存，分发时由各平台转换。用户选定多个平台后，编辑器应能说明哪些功能适用、哪些会转换、哪些无法发布；不要静默丢弃内容。

## 暂缓项

格式刷、大量字体/任意字号、装饰模板、平台表情全集、AI 配图/润色、商业组件暂不优先。先确保内容稳定保存、编辑操作明确和跨平台排版可预期。

另外，B 站当前页面出现 AI 辅助创作声明，此项属于账号发布表单的后续核对范围，不属于正文工具栏。

## 下一步验证

- 各平台标题层级、图片描述、外链允许范围及文字格式保存结果。
- 标准正文样例经过导入、重新加载及平台输出后，结构和内容是否保留。

## 实施进度（2026-10-05）

已完成基础编辑体验：格式按钮显示选区状态；提供撤销/重做入口及快捷键提示；清除格式保留正文图片和描述；链接使用现有 Dialog/Field/Input 组件，支持插入、修改、移除及地址校验；粘贴清理装饰样式并保留基础结构；超限输入明确提示且不重置编辑历史。已关闭代码与代码块扩展，不新增表格、公式或平台专属内容。

粘贴遇到表格或代码时仅保留普通文字；无法保留的内容有简短反馈，不提供这些内容的编辑或转图片功能。基础粘贴整理不承诺完整还原 Word 排版。

第二批已实现：本机自动保存与恢复覆盖正文、封面和账号设置；切换页面时刷新恢复副本，手动保存成功后清理副本。副本按稿件隔离，并核对服务端修改时间，避免恢复旧版本。增加可折叠目录、固定工具栏、专注写作及手机/桌面宽度阅读预览；预览可切换分发账号，明确标为本地效果。无路径的剪贴板图片先保存为本机 PNG 再插入。

文档导入支持 Markdown、HTML、TXT、DOCX，插入当前光标处，保留基础文字结构。DOCX 嵌入图片先落到本机；取消图片保存则不插入半篇文档。表格、代码和公式仅保留可读文字，不提供对应编辑功能。导入不保证完整还原 Word 样式。

第三批已实现：正文/标题/小标题选择，以及更多格式中的删除线、分割线、三种对齐方式、三种文字颜色、两种背景色。扩展文字样式随通用稿件保存；本地预览和分发输出共用保守规则：抖音、头条简化未核实的样式，B 站保留限定样式，抖音还将删除线与分割线转为普通文字或移除。预览提示转换结果，原稿不受影响。

实际平台保存和发布后的样式仍待实测；当前文章发布适配器尚未完成，不能把本地预览当作平台效果验证。自动保存是本机恢复副本，进入作品列表仍需手动保存草稿。

工具栏审查后按历史、段落样式、文字格式、列表与引用、图片与链接、清除与更多格式分组；目录、阅读预览和专注写作独立靠右。文档导入移到正文标签行，专注模式仍可使用。移除独立字号入口，已有稿件和导入内容的限定字号仍可保留。专注模式使用全屏对话框，顶部避让窗口控制区，切换时保留编辑器及撤销记录。
