## 头条赞赏额度

赞赏不采用固定“每天 5 次”的配置。业务窗通过专用 IPC 请求主进程，主进程从本机 Server 取得当前头条账号凭证，在临时隔离的隐藏窗口打开空白文章编辑器，只读取 `允许赞赏` 复选框的平台原文与禁用状态。读取结束销毁窗口并清理会话；凭证不会返回业务 renderer。

- 原文例如“允许赞赏（今日还有5次机会）”，数字按当前账号和当前平台显示。
- 剩余 0 次或平台禁用时取消并禁用勾选。读取中或失败时禁用操作；失败显示“赞赏次数暂未获取”，可刷新。
- 进入账号设置、窗口重新获得焦点及页面可见期间每分钟重新读取；账号之间隔离，不在草稿中保存额度、不自行递减次数。
- 普通浏览器没有桌面桥时无法读取额度，不伪造次数。实际文章发布适配器接入后仍需发布前重新核对能力。
