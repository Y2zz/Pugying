# 图文发布：核心目标与验收标准

1. **一条图文**：多图轮播（有序 `mediaPaths`）+ 标题 / 文案分离（纯文本 `body`）+ 竖版封面为主（可自首图裁切）
2. **多方分发**：抖音图文、头条微头条、小红书图文、视频号图文；同平台可多选账号，各一份 Target
3. **个性化**：图片与文案共用；其余按账号走独立平台表单
4. **持久化**：保存草稿（Content `type=graphic` + Targets + overrides + 封面 BLOB）
5. **与文章区分**：图文是图文分离；文章是富文本内嵌图，见 [`publish-article.md`](publish-article.md)
6. **约束**：不改 `components/ui/**`；用户文案克制

## 存量

- 历史上 `type=article` 且按「多图 + 竖封面」发布的内容，迁移后为 `graphic`

## 图片编辑

- 图片可拖放排序，也可聚焦图片槽位后用方向键移动；轮播、保存和发布沿用当前顺序。
- 每张图片可选择比例、拖动裁剪框内部移动图片、拖动边线移动裁剪框、拖动四角调整大小，并以 100%～300% 缩放图片。边线支持方向键移动裁剪框；内部支持方向键移动图片。裁剪框的移动和大小调整按缩放、平移后的实时图片边界与可见预览区的交集计算，不受初始化图片边界限制。缩小图片或预览区时，裁剪框保持比例适配新边界；图片始终覆盖裁剪区，导出与预览一致。
- 确认裁剪后另存本机 PNG，并替换该位置的 `mediaPaths`；原文件保留。取消不改动图片，保存失败可重试。
- 缩略图及首图封面经桌面接口读取本机图片，不依赖界面直接加载 `file://`。

## 表单验证交互

- 保存校验失败使用 Toast 提示并聚焦问题字段；字段修正后错误提示立即消失。草稿仍允许缺文案、图片、封面和账号。
- 标题字段、检查项及保存共用同一上限和计数规则；标题失焦整理连续空白。文案按实际保存文本计数，保留段落及连续空白。
- 点击文案或图片检查项时显示字段提示并聚焦文案框或添加图片槽位；点击封面检查项时标红缺失槽位并聚焦。未选账号时，封面要求待账号确定。
- 点击账号检查项聚焦绑定或添加入口；点击账号设置检查项先切换到对应账号，再定位错误控件。
- 页头与文章页一致：次要操作保存草稿，主要操作发布图文。直接发布须通过全部检查，先保存内容及通用／账号封面，再提交本机分发队列；提交中锁定操作并显示「提交中…」，成功提示「已开始分发」后返回作品管理。失败留在表单，可重试且复用已保存的草稿。

## 头条与小红书图文接入

图文直接发布沿用文章的保存、校验、提交队列与回执交互。当前真实适配器支持抖音、头条微头条、小红书与视频号图文。对接要求与视频号一致：**Cookie HTTP 直调**；上传与接口签名在主进程解决，不得依赖隐藏窗页面 SDK。

| 平台       | 图片       | 标题／文案                                  | 封面       | 可见范围／时间           |
| ---------- | ---------- | ------------------------------------------- | ---------- | ------------------------ |
| 头条微头条 | 最多 18 张 | 标题最多 100 字，标题与文案合计最多 2000 字 | 无单独封面 | 公开、立即发布           |
| 小红书图文 | 最多 18 张 | 标题最多 20 字、文案最多 1000 字            | 首张图片   | 公开／仅自己；立即／定时 |
| 视频号图文 | 最多 18 张 | 标题可选最多 30 字，标题／文案／话题合计最多 1000 字 | 首张图片   | 公开／仅自己；立即发布   |

- 微头条已改为 **Cookie 直调**（无隐藏窗）：`/spice/image` 上传图片 → `/mp/agw/article/wtt` JSON 提交；标题置于正文首行，作品声明的 `extra.info_source` 按官方设置组件要求保存为 JSON 字符串。
- 小红书图文已改为 **Cookie 直调**（无隐藏窗）：创作者域 `upload/web/permit` → ROS PUT 上传（无需 `x-s`）→ `edith` `/web_api/sns/v2/note` 由主进程补 `x-s`/`x-t`（XYS_ / mns0301）。定时范围为 1 小时至 14 天，按官方字段使用毫秒时间戳；定时边界尚未实发验证。
- 两个平台无需额外上传通用封面；检查项显示「无需单独设置」。各账号的限制和声明独立校验，失败可直接定位对应控件。
- 平台关联话题与位置选择器尚未接入，文案可使用普通话题文字。旧草稿独立话题字段必须移入文案后才允许发布，避免静默遗漏。
- 平台明确拒绝时允许重试；提交后发生断网、超时或缺少有效作品 ID 时保留待确认状态，不自动重发。小红书成功响应可能无 `code` 或填入 `N/A`，仅在同时返回成功标志及有效作品 ID 时确认成功。
